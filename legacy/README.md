# Legacy code

`v0/` is the original prototype of Norman The Machine, kept unchanged for reference.
It is not part of the `norman` package, is not tested, and is not compatible with
the current model. See the "Project history" section of the main README for why it
was rebuilt.

To run it, work inside `v0/` and follow `v0/README.md`. Build the `norman_core`
extension with its own `CMakeLists.txt`.
